# 판매예측-공급망조율 멀티에이전트 (S&OP 개념 기반)

판매예측과 공급망조율 사이의 반복 조정을, 여러 agent가 서로의 판단에 실제로 영향을
주는 구조로 구현하는 프로젝트입니다.

이전 프로젝트인 [logistics-agent-poc](https://github.com/taeri-sudo/logistics-agent-poc)에서
"여러 agent가 실제로 서로의 판단에 영향을 주는 구조(Agent-to-Agent)"를 지향점으로
뒀으나 실제로는 달성하지 못했다는 걸 코드 리뷰로 발견했고, 이 프로젝트는 그 구조를
실제로 구현하는 데 목적이 있습니다.

## 현재 상태

설계 완료, 구현 진행 중입니다.
